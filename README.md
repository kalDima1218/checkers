# Checkers

Веб-приложение для игры в шашки (человек vs человек или человек vs бот) на Go.

## Возможности

- регистрация и вход пользователей;
- авторизация через cookie с JWT;
- игра против другого игрока через очередь ожидания;
- игра против бота;
- просмотр и обновление состояния партии через HTTP API.

## Технологии

- Go 1.20
- MySQL
- HTML/CSS/JavaScript (без отдельного frontend-фреймворка)

## Быстрый старт

1. Установите Go 1.20+ и MySQL.
2. В корне проекта создайте `config.json`:

```json
{
  "User": "your_mysql_user",
  "Passwd": "your_mysql_password",
  "Addr": "127.0.0.1:3306",
  "DBName": "checkers"
}
```

3. Подтяните зависимости:

```bash
go mod tidy
```

4. Запустите приложение:

```bash
go run .
```

По умолчанию сервер поднимается на `http://127.0.0.1:8080`.

## Основные страницы

- `GET /` — главная страница (лобби)
- `GET /game?id=<game_id>` — страница партии
- `GET /registration` — регистрация
- `GET /login` — вход
- `GET /waiting_game` — ожидание соперника

## Основные API-эндпоинты

- `GET /start_game` — встать в очередь для игры с игроком
- `GET /start_bot_game` — начать игру с ботом
- `GET /get_waiting` — проверить, найден ли соперник
- `GET /stop_waiting` — выйти из очереди
- `GET /make_move?id=...&from_x=...&from_y=...&to_x=...&to_y=...` — сделать ход
- `GET /end_move?id=...` — завершить ход
- `GET /whose_move?id=...` — узнать, чей ход
- `GET /get_side?id=...` — получить сторону текущего игрока
- `GET /get_players?id=...` — получить имена игроков
- `GET /who_win?id=...` — получить статус победителя
- `GET /get_last_move_number?id=...` — получить номер последнего хода
- `GET /get_board_hist?id=...&turn=...` — получить доску на указанном ходе

## Структура проекта

- `main.go` — точка входа
- `site.go` — маршрутизация и запуск HTTP-сервера
- `auth.go` — регистрация, вход, JWT-сессии
- `game.go`, `game_api.go` — игровая логика и API
- `bot.go` — логика бота
- `db.go` — работа с MySQL
- `html/`, `css/`, `js/` — клиентские файлы
